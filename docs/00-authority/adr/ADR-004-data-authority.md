# ADR-004: データ正本は SQLite、コンテンツ実体は WordPress、Notion は非判定の同期先

- status: accepted
- date: 2026-07-30
- decision_authority: PO（charter §3/§10 で確定済みの判断を ADR 化）
- 関連: BR-G2、FR-45/55/71、NFR-3/5/10

## 決定

- 状態・数値・証跡の正本は **SQLite 単一ファイル**（ループ判定はここだけを見る）
- コンテンツ実体（テキスト・画像・動画・音声）は **WordPress** に収束し、SQLite は参照のみ
- **Notion** は計画・ネタの人間 UI として低頻度同期のみ。判定に関与させず、障害時もループは継続

## 理由

個人規模でサーバレス・再開性（NFR-3）・1 クエリ可観測性（NFR-5）を満たす最小構成。実体とメタの分離でどちらの障害も局所化する。

## 帰結

- SQLite は日次バックアップ＋世代保持（NFR-10、RSK-06）
- Postgres 移行は個人規模を超えた時点で再検討（現状トリガーなし）
