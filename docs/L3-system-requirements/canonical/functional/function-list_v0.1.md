## 上流戦略層との関係（2026-08-01 追補）

上流戦略層の実装単位は [strategy-loop-design_v0.1.md](../../../L4-basic-design/canonical/components/strategy-loop-design_v0.1.md) の
SCM 台帳が正本（SCM-05〜10 は S1+ の上流戦略スライス）。S0 分（brief シード・保持ガード・TLP 生成）は
FN-701/702（CMP-05／DU-10/11 — DDL・migration）・FN-101（CMP-01／DU-01 — start ガード）・

本一覧の FN 数・スライス配分は変更しない（SR-15）。

- 全 FN が FR / NFR / MR の実在 ID に trace する（BR 直接参照 0 件）
