## 1. WordPress（WP）

**構造（調査値)**: REST API は投稿/メディア/タクソノミーの CRUD 完備。Application Passwords は
コア標準・HTTPS 必須・**権限粒度はユーザー単位のみ**（パスワード別スコープなし）。
コアにレート制限なし（自主設定前提）。セルフホストは API 利用の規約制限なし。

- **BR-M-WP-1** 専用ボットユーザー（Editor 相当の最小ロール）を作り、ハーネスはそのユーザーの
  Application Password のみで書き込むこと。Administrator 権限をハーネスに渡さない
- **BR-M-WP-2** レート制限はコアに無いため、書き込み自制（MR-WP-5）をハーネス側の責務とすること
- **BR-M-WP-3** パスワードは個別発行・個別失効・最終使用日時の追跡を運用に組み込むこと（漏洩時の局所化）

## 2. X（X）

**構造（調査値）**: 無料は 280 字・**50 投稿/日・200 リプライ/日**（2026-05 頃導入・目安）。
長文（25,000 字）・記事・予約投稿・**アカウント全体アナリティクスは Premium 専用**。
規約（User Agreement / Automation Rules / Platform Manipulation and Spam Policy）はブラウザ自動化を
明示禁止。**2026-02 以降、非公認ツール利用アカへの大規模 BAN 波が報告**（目安）。

- **BR-M-X-1** 日次投稿計画は無料枠 50 投稿/日を大幅に下回る水準（MR-X-3: 5 件/日）で設計し、
  枠の残量を意識した運用をしないこと（上限に近づく運用自体を禁止）
- **BR-M-X-2** アカウント保全を最優先とし、警告・認証要求・シャドウバン兆候の検知を計測対象に含めること
- **BR-M-X-3** KPI 計測は**個別ポストの画面値（インプレッション・エンゲージメント数）に限定**して
  KPI ツリーを設計すること（決定 2026-07-31・§99-5。プロフィールアクセス等の全体アナリティクスは
  Premium 専用のため対象外。ゼロ固定費原則により Premium は採らない。実績証跡が課金価値を示した
  場合のみ再検討トリガー）
- **BR-M-X-4** ⚠ ブラウザ自動化は規約明示違反であり、2026 年時点で執行が強化されている。
  **X へのブラウザ書込みは事前禁止（prohibited）とする**（2026-08-01 PO 決定・レビュー対応 —
  撤退条件つき試行ではなく最初から実施しない。公式 API 未採用の間は attended 人手投稿又は降格）

## 3. note（NOTE）

**構造（調査値）**: 無料/プレミアム（月500円: 予約投稿・定期購読マガジン）/pro。有料記事は無料でも
可（100〜50,000 円）。メンバーシップ手数料 10%・定期購読マガジン 20%。公式 API 非公開、規約の禁止事項に
「プログラムによる自動的な情報収集」。**アナリティクス β と販売履歴は CSV エクスポート可**（4 SNS 中最良）。

- **BR-M-NOTE-1** 計測は公式 CSV エクスポート（アナリティクス β・販売履歴）を第一経路とし、
  画面スクレイピングを計測目的で使わないこと
- **BR-M-NOTE-2** 有料記事・マガジン価格は金銭 escalation（BR-C4）。手数料率（10%/20%）を
  収益 KPI の原価として KPI ツリーに織り込むこと
- **BR-M-NOTE-3** 定期購読マガジン開設（プレミアム必須・月 1 回以上更新義務）を採用する場合、
  更新義務をスプリント計画の制約として登録すること
- **BR-M-NOTE-4** AI 量産的な大量投稿は削除・停止事例があるため、公開頻度は品質ゲート通過分のみ・
  少量高品質を原則とすること

## 4. YouTube（YT）

**構造（調査値）**: 電話確認で 15 分超動画・カスタムサムネ解禁。ショートは 3 分以内。
Studio アナリティクスは全アカウント無料で詳細・**CSV エクスポート可**。
規約はスクレイパー等の自動アクセスを明示禁止。2026-07 のポリシー更新で
**inauthentic content（AI 量産・独自性なし）の収益化剥奪・推薦除外を強化**。AI 生成コンテンツは開示義務。

- **BR-M-YT-1** チャンネル開設直後に電話確認を済ませ、アドバンス機能を有効化してから運用を開始すること
- **BR-M-YT-2** AI 生成を含む動画は開示フラグを必ず立てること（開示漏れをゲートで検証）
- **BR-M-YT-3** 量産ではなく 1 本の品質と独自性を優先すること（inauthentic content 判定の回避。
  同一素材からのショート派生 MR-YT-2 は「独自性のある編集」を伴うこと）
- **BR-M-YT-4** 計測は Studio の CSV エクスポートを正とすること（取得証跡付き・BR-E2）

## 5. Instagram（IG）

**構造（調査値）**: プロアカウント（無料）でインサイト解禁。フィード/カルーセル最大 20 枚/リール/
ストーリーズ。アクション上限は非公式で厳しい（フォロー約 150/日・コメント 12〜14/時 目安)。
検知は 4 SNS 中最強。**インサイトのネイティブ CSV エクスポートは実質なし・保持約 90 日**。
⚠ **公式 Graph API（コンテンツ公開 API）が無料で存在**（プロアカウント要）。

- **BR-M-IG-1** 接続は**公式 Graph API（無料・プロアカウント）を第一経路とする**（決定 2026-07-30・
  §99-1・ADR-006）。投稿・インサイト取得とも API で行い、ブラウザ操作は API 未対応の attended 作業に限定
- **BR-M-IG-2** フォロー・いいね等のグロースハック系アクションは行わないこと（検知リスクに対して
  リターンが薄い。公開と応答に限定）
- **BR-M-IG-3** インサイトは 90 日で消えるため、計測取り込みは月次以上の頻度で行い SQLite に永続化すること
- **BR-M-IG-4** ビジュアル審査（design-evidence）を品質ゲートに含める（MR-IG-1 の業務要求承格）

## 6. Discord（DC）

**構造（調査値）**: Bot は無料・100 サーバー未満なら privileged intents（メッセージ本文含む)は
Portal トグルのみで有効。レートはグローバル 50 req/秒、メッセージ約 5 通/5 秒/チャンネル。
**self-bot（ユーザーアカウント自動化）は明示禁止**。Server Insights はメンバー 500 人以上required。

- **BR-M-DC-1** 自動化はすべて Bot アカウント経由とし、ユーザーアカウントの自動操作を設計から排除すること
- **BR-M-DC-2** Bot 権限は必要最小限のビットフィールドで招待すること（管理権限を持たせない）
- **BR-M-DC-3** 500 人未満の間は Server Insights が使えないため、活性度計測（DAU・発言数）は
  Bot の自前収集で設計すること
- **BR-M-DC-4** メッセージ送信はチャンネル毎 5 通/5 秒のレート内でキューイングすること

## 7. ポッドキャスト（PC）

**構造（調査値）**: RSS はプル型のため **WP 自動投稿→自動配信は完全に正常な利用形態（規約リスクなし）**。
初回のみ各ディレクトリ登録＋メール認証が手動。アートワーク 1400–3000px 正方形、MP3 44.1kHz、
エピソード上限 Apple 512MB/Spotify 200MB（目安）。Spotify/Apple/Amazon とも計測 CSV DL 可。
却下最多要因はアートワーク不適合と WAF がクローラを遮断するケース。

- **BR-M-PC-1** 初回ディレクトリ登録（Spotify/Apple/Amazon）は人の作業として計画し、
  以降の配信は RSS 自動更新のみで完結させること（本媒体は自動化リスクゼロの主力候補）
- **BR-M-PC-2** RSS の GUID を一度発行したら変更しないこと（重複エピソード事故の防止）
- **BR-M-PC-3** WP 側の WAF/CDN 設定が各社クローラを遮断しないことを配信前チェックに含めること
- **BR-M-PC-4** 計測は 3 ディレクトリの CSV を統合し、横断再生数を単一 KPI ノードへ集約すること

## 8. stand.fm（STFM）

**構造（調査値）**: PC web から外部音源アップロード可（m4a/mp3/wav・200MB・最大 1 時間）。
公式 API なし。規約第 7 条が非公式手段での閲覧・再生数不正を禁止。**計測のエクスポート機能なし**。
収益化プログラムは 2024 年の運営移管後に条件変動が続く（事業リスク）。

- **BR-M-STFM-1** 従媒体（Podcast の音源流用先）と位置づけ、専用制作をしないこと
- **BR-M-STFM-2** 計測はエクスポート不能のため、画面値の低頻度取得（スクショ証跡）に留め、
  KPI 上も参考値扱いとすること
- **BR-M-STFM-3** 収益化プログラムには依存しないこと（条件変動リスク。収益 KPI に組み込まない）

## 9. Amazon KDP（KDP）

**構造（調査値）**: 公式 API なし（Amazon 明言）。**新規タイトル 1 日 3 冊制限**。審査最大 72h。
ロイヤリティ 70% は JP 税込 250〜1,250 円＋ KDP セレクト（90 日独占）必須、35% は 99〜20,000 円。
**AI 生成コンテンツの申告義務あり（虚偽申告はアカウント停止事由）**。低品質 AI 大量出版への執行が
2026 年に強化。累犯で全タイトル削除＋ロイヤリティ没収。

- **BR-M-KDP-1** AI 申告を出版ワークフローの必須ステップとし、申告内容を evidence に記録すること
- **BR-M-KDP-2** 価格戦略はロイヤリティ体系（70% 帯 250〜1,250 円＋セレクト独占 / 35% 帯）を
  型として保持し、価格設定は金銭 escalation（BR-C4）とすること。セレクト独占（90 日）は
  他媒体展開（note 有料記事等）と排他になるため、束縛承認の判断材料に含めること
- **BR-M-KDP-3** 出版は月数冊以内の低頻度・高品質とし、1 日 3 冊制限に近づく運用をしないこと
- **BR-M-KDP-4** 計測はKDP レポートの XLSX/CSV DL を正とすること
- **BR-M-KDP-5** Amazon アカウントは購買と共用のため、警告兆候で即時全自動操作を停止すること（RSK-01 特例）

## 10. HubSpot（HS）

**構造（調査値）**: 無料枠は**メール月 2,000 通**・コンタクト 100 万件・フォーム。
**公式リモート MCP が 2026-04 GA・無料ティア含む全プランで利用可**（OAuth 2.1）。
API は 100 req/10 秒・約 25 万コール/日（目安）。特定電子メール法: 同意記録の保存
（配信停止後 1 か月、措置命令時 1 年）・送信者表示・オプトアウト導線が義務。

- **BR-M-HS-1** 自動化は公式 MCP/API のみで行うこと（ブラウザ補完は初期設定等の attended 作業に限定）
- **BR-M-HS-2** 月 2,000 通を配信予算として月初に配分計画を立て、セグメント配信のみとすること
- **BR-M-HS-3** オプトイン同意の方法・日時を記録し、法定保存期間を data retention 要件に含めること
- **BR-M-HS-4** 送信者氏名・住所・受信拒否導線を配信テンプレートの必須要素として機械検証すること（NFR-9）

## 11. LINE 公式アカウント（LINE）

**構造（調査値）**: 無料 200 通/月（追加購入不可の硬い上限）。応答メッセージ（自動応答）は
カウント対象外。**Messaging API は無料・全プランで利用可**（課金は通数のみ）。
2026-10 に従量料金の改定予定。

- **BR-M-LINE-1** 配信は **Messaging API（無料・公式）を第一経路とする**（決定 2026-07-30・§99-2・
  ADR-006）。200 通/月の上限は管理画面と同一で、規約リスクのみが消える。管理画面は attended 設定作業のみ
- **BR-M-LINE-2** 200 通/月を配信予算とし、週 1 回・1 セグメント以内を既定とすること（MR-LINE-3）
- **BR-M-LINE-3** 応答メッセージ（無料・無制限）を一次対応に活用し、プッシュ配信は
  見込み度上位セグメントに温存すること
- **BR-M-LINE-4** ブロック率を媒体健全性 KPI とし、閾値超過でセグメント配信を停止すること（MR-LINE-2）

## 12. Stripe（STRIPE）

**構造（調査値）**: 国内カード 3.6%・銀行振込 1.5%・固定費なし。API ファースト設計で自動化は公式に正当。
Sigma（SQL 分析）は有料オプション。

- **BR-M-STRIPE-1** 手数料（3.6% 等）を収益 KPI の原価として KPI ツリーに織り込むこと
- **BR-M-STRIPE-2** レポートは無料のダッシュボード CSV / Reports API を使い、Sigma（有料）は
  導入しないこと（固定費ゼロ原則）
- **BR-M-STRIPE-3** 金銭操作の束縛承認（BR-C4）は API 経由でも同一に適用すること

## 13. アフィリエイト / ASP（AFF）

**構造（調査値）**: A8=審査なし登録・最低支払 1,000〜5,000 円・振込手数料 66〜660 円。
もしも=最低 1,000 円・手数料無料。Amazon=180 日以内に適格販売 3 件で本審査、PA-API は売上実績連動。
楽天=楽天キャッシュ 1 円から。**成果データ取得の公式 API は A8/もしも/楽天に存在しない**。
楽天は「プログラムによる機械的な投稿等」を明示禁止。ステマ規制: PR 表記はファーストビュー内の
明瞭表示が必要（末尾・「※」のみは不可）。ASP 各社も媒体側の PR 表記を規約で義務化（違反で提携解除）。

- **BR-M-AFF-1** ASP 自動化範囲は次で確定（決定 2026-07-31・§99-8）: **楽天は自動操作対象外**
  （規約明示禁止・fail-close）。他社 ASP の自動操作は**低頻度の読み取り（成果レポート取得）のみ**とし、
  提携申請等の書き込み系は attended、リンク掲載は制作パイプライン側で完結する
- **BR-M-AFF-2** PR 表記はファーストビュー内配置を表記ゲート（FR-24）の検証条件に含めること
  （表記の存在だけでなく位置も検証）
- **BR-M-AFF-3** ASP 選定は もしも（手数料無料・低額支払）と A8（案件数）を主とし、
  Amazon は 180 日 3 件の本審査要件をスプリント計画に組み込むこと
- **BR-M-AFF-4** 成果レポートは記事単位で SQLite に紐づけ、収益 KPI の一次データとすること（MR-AFF-2）

## 14. PWA（PWA）

- **BR-M-PWA-1** 診断ツール等は PWA 化を標準とし、Lighthouse スコア 80 以上（目安）を品質ゲートに含めること
- **BR-M-PWA-2** オフライン対応・通知等の付加価値を最初から設計に含めること
  （Play 展開時の「単なるサイトラッパー」却下（ポリシー 4.3）の予防）

## 15. Google Play / TWA（PLAY）

**構造（調査値）**: $25 買切＋本人確認。**個人アカウントは「12 名のテスターが 14 日間連続オプトイン」の
クローズドテスト要件（2026 年も有効）**。Target API 36（2026-08-31 以降）。
**Play Developer API で公開まで自動化可能（公式サポート・唯一の完全正当自動化媒体）**。
最大却下リスクはポリシー 4.3（Minimum Functionality）のサイトラッパー判定。

- **BR-M-PLAY-1** 本媒体は**保留へ降格**（決定 2026-07-31・§99-7）。個人アカウントの 12 テスター×14 日
  要件の充足手段の証跡が揃った時点で再昇格を判断する。PWA 主線（BR-M-PWA-*）は不変。
  保留中は BR-M-PLAY-2/3 も休眠（要求としては維持）
- **BR-M-PLAY-2** リリース自動化は Play Developer API（公式）で行うこと（ブラウザ操作は初期設定のみ）
- **BR-M-PLAY-3** TWA はオフライン・通知等の付加価値実装（BR-M-PWA-2）を却下対策の前提とすること

## 16. Canva（CANVA）

**構造（調査値）**: 公式 MCP あり（OAuth・Free プランでも接続可）。ただし **ストック素材の検索・取得
API は提供なし**（検索対象は自分のデザイン/アセットのみ）。**アセットアップロード API は Pro 必要**。
エクスポート 500 件/日・75 件/5 分（目安）。ライセンス: 商用利用可、素材単体の再配布・再販・
商標登録利用は禁止。

- **BR-M-CANVA-1** 「ストック素材取得」は MCP では実現できない（調査で判明）。素材調達は次で確定
  （決定 2026-07-31・§99-6）: デザイン生成は MCP、ストック相当素材は **Codex CLI image_gen
  （BR-M-GENAI-4）と Openverse 等の無償源を主経路**、Canva ストックはエディタ内で人が選ぶ
  attended 補助のみ（ブラウザ自動取得は行わない）
- **BR-M-CANVA-2** Canva 素材を含む成果物の「単体再配布・再販・商標利用」を公開ゲートの禁止条件に
  含めること（リードマグネット配布は成果物として問題ないが、素材集としての配布は不可）
- **BR-M-CANVA-3** ライセンス種別と利用先の紐づけ（MR-CANVA-1）を業務要求として維持すること

## 17. 生成 AI（GENAI）

**構造（調査値）**: **3 社（OpenAI/Google/xAI）とも消費者向け Web UI の自動操作は明文の規約違反**
（OpenAI「API 経由以外の自動的手段」禁止 / Google「自動化された手段」禁止 / xAI「bot・script による
アクセス」禁止）。**Google は違反時に Google アカウント全体（GA4/Search Console/Gmail）の連座停止
リスクあり**。出力の商用利用は 3 社とも可（xAI はライセンス条件が最もユーザーに不利）。

- **BR-M-GENAI-1** ⚠ Web UI 自動操作は 3 社とも規約明示違反であることを PO が認識した上で
  採否を決定すること。少なくとも **Gemini は自動操作対象から外す**（GA4/GSC と同一 Google アカウントの
  連座停止は事業全体を止める。RSK-09）
- **BR-M-GENAI-2** 自動操作を行う場合も、計測・広告等の基幹 Google アカウントと生成 AI 用アカウントを
  完全分離すること
- **BR-M-GENAI-3** 生成物の商用利用条件（各社の出力権利規約）を素材登録時にライセンス種別として
  記録すること（BR-M-CANVA-3 と同じ台帳）
- **BR-M-GENAI-4** 静的画像の生成は **Codex CLI 内蔵 image_gen**（`codex exec` 非対話・ChatGPT Pro
  サブスク枠・追加費用なし）を第一経路とすること（PO 決定 2026-07-30・動作確認済）。CLI は OpenAI が
  提供する正当な自動化インターフェースであり Web UI 自動操作の規約リスク（RSK-08/09）を伴わず、
  レート節度（BR-F5・人間模倣の間隔制御）の対象外（PO 判断 2026-07-30）。制御は間隔でなく**総量**で
  行う: 日次生成枚数上限（充填: C。1 指示で 10 数枚のバッチは正常運用として通る水準に設定）を
  安全弁とし、生成枚数を使用量として SQLite に記録すること。429・usage-limit 応答は正常系として
  扱い翌期間まで当該経路を停止（アカウント切替等での迂回禁止）、恒常的に上限へ達する場合は
  Images API（従量・明示レート仕様）への切替を再検討トリガーとすること。
  生成元ファイル（`~/.codex/generated_images/`）のハッシュを証跡とすること

## 19. GA4 / Search Console（MEAS）

**構造（調査値）**: GA4 探索は CSV 最大 10 万行・無料版のデータ保持は既定 2 か月→最大 14 か月。
GSC は **UI エクスポート 1,000 行切り詰め・データ保持 16 か月**。API（GA4 Data API / Search Analytics
API 25,000 行）と BigQuery エクスポートは無料の正規自動化経路。**UI の Playwright 自動化はグレー**で、
違反認定時は Google アカウント全体の停止リスク（GENAI と同じ連座構造）。

- **BR-M-MEAS-1** ⚠ 計測の自動取得は **GA4 Data API / Search Analytics API（無料・正規）を第一経路**に
  再設計すること（charter「ブラウザエクスポート」の再考。API の方が行数上限も緩く証跡も安定する）
- **BR-M-MEAS-2** GA4 のデータ保持を初期設定で 14 か月へ変更し、それを超える履歴は SQLite 側を
  正本とすること（GSC 16 か月も同様）
- **BR-M-MEAS-3** UI エクスポートを使う場合は 1,000 行制限（GSC）を前提に、詳細データは API で補完すること
