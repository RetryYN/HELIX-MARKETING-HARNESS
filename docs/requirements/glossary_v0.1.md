# 用語集 v0.1

> status: **confirmed**（2026-07-31 PO 承認 — 要件定義完遂指示。AI 起草）
> 本書がプロジェクト独自語の正本。各文書の凡例は本書への参照とする。

| 用語 | 定義 |
|---|---|
| ペア成立 | 対になる 2 レコード（企画↔審査 PASS、KPI 目標↔計測スナップショット）が両参照付きで SQLite に揃った状態。片方だけでは下流動作（公開・レビュー）が許可されない |
| 片肺 PASS（片肺禁止） | ペアの片側だけで完了扱いにすること。本ハーネスでは構造的に不可能とする（BR-B1/B2） |
| 攻略地図（playbooks） | ブラウザ自動化の対象サイトごとの構造・手順・セレクタ・最終成功日時を DB に蓄積したもの。破損時は自己修復 1 回→エスカレーション（FR-42/43） |
| 束縛承認 | 対象・操作・時点を明記した承認要求を人に送り、応答が証跡化されるまで対象タスクを進めない承認方式（FR-46） |
| オートモード | 安定稼働基準（config）の証跡が揃った媒体で、束縛承認を省略して公開まで自走する状態。金銭操作は常時対象外（FR-26） |
| 型×動的充填 | スキーマ（型）をコードに持ち、値はヒアリング/リサーチ/config で動的に充填する設計原則。値のハードコード禁止 |
| 充填経路 H/R/C | H=ヒアリング（人に照会）/ R=リサーチ（Web 検索で起草）/ C=config（設定値）。要求・要件の値がどこから来るかの宣言 |
| マイクロ CV | 最終転換の手前の小さな転換行動（CTA クリック・資料 DL・診断完走など）。KPI ツリーの中間層 |
| オーガニック版 MMM | 広告費ゼロ前提で媒体横断の寄与を推定するマーケティング・ミックス・モデリング（将来 S3+、R 導入トリガー） |
| ブラウザ突破 | 公式 API がない/貧弱な媒体をブラウザ自動化（Playwright→Camoufox→ビジョン）で操作すること |
| 証跡（evidence） | 完了判定の根拠となる記録（公開 URL・計測値・審査記録・commit hash・スクショ/ファイルハッシュ）。宣言のみの完了を構造的に不可能にする（BR-B3） |
| fail-close | 判定不能時に「通さない」側へ倒すゲート原則。ゲート無効化フラグを持たない（NFR-1） |
| スライス（S0/S1/S2/S3+） | 実装の段階分割。S0=ウォーキングスケルトン（1 記事の一気通貫）、以降は機能一覧の配分に従う |
| ウォーキングスケルトン | 全レイヤを最小限つなげて 1 件を端から端まで通す初期実装（S0） |
| 三エンジン | ヒアリング/リサーチ/設定管理の 3 充填エンジン（FR-3x）。型×動的充填の実行主体 |
| 検証マイクロループ | タスク内の 実行→検証→差し戻し の反復。author≠verifier（自己審査禁止）で PASS のみ完了 |
| 意味モデル（戦略正本） | 上流戦略ループが更新する機械可読モデル群（market_observation〜strategy_revision の 12 モデル。json/strategy/ の schema が正本）。「なぜその結果が発生したと考えるか」を保持する。KPI ツリー（観測背骨）とは分離 |
| strategic_brief | 上流の行動計画が下流へ発行する発注契約（digest・版・有効期間・媒体役割・認識変化・計測計画付き）。下流ループは有効な brief なしに開始できない（SR-06/07） |
| tactical_learning_packet（TLP） | 下流ループが完了時に上流へ提出する還流契約。観測事実・AI 解釈・因果推論・反証可能仮説の判定・推奨判断を分離フィールドで持つ。下流→上流の唯一の経路（SR-08/09） |
| strategy_revision | 上流の改善工程の出力。どの意味モデルを maintain/refine/pivot/reject/retire するかを根拠・反証・信頼度・対象版付きで記録。単一計測値だけの自動 accept は拒否（SR-10） |
| 媒体役割（media_role） | 媒体の戦略上の役割語彙（problem-framing・proof・conversion 等 12 語彙。media-roles.json 台帳が正本）。媒体名は役割ではない（SR-14） |
| 状況ベースセグメント | 時間・空間・状況・制約・進行状態・代替行動・意思決定条件を中心に定義するセグメント（segment_context）。人口統計ペルソナの正本化は禁止（SR-04） |
| 認識変化資産 | コンテンツの正式な位置づけ — 市場の問題認識・カテゴリー・比較軸・選択基準・価値認識を定義・変化させる資産。主要企画は 5 宣言必須（SR-13） |
